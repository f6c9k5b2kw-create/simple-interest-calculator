
# Code of Conduct

## Our Pledge
We pledge to provide a welcoming and harassment-free environment for everyone.

## Our Standards
Treat everyone with respect and accept constructive feedback.

## Enforcement Responsibilities
Project maintainers are responsible for enforcing this code.

## Scope
This code applies to all project and community spaces.

## Enforcement
Report unacceptable behavior to the project maintainers.

## Enforcement Guidelines
1. Correction
2. Warning
3. Temporary Ban
4. Permanent Ban
